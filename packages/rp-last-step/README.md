# DSH RP 最后一步

独立的 DSH 0.2.1-rc.2 插件：导入或自建提示词模块，借助配套 skill 生成 agent 范式迁移草稿；用户固定必用和 Agent 只读模块，其余由模型在最后呈现前动态组装。模拟、工具判定和世界状态继续由现有 agent／工具提供。

## 安装

完全退出 dsh 后执行：

```powershell
dsh plugin --profile desktop add ./dsh-rp-last-step-0.1.0.tgz
```

Web 模式将 `desktop` 改为 `web`。重启后点击“预设”，或在原生右侧新增页签中选择“RP 最后一步”。安装包不附带世界、角色、故事或第三方提示词包。

## 使用

1. 导入 SillyTavern JSON，或新建空白预设。原始导入文本独立保存，用户文件不会被回写。
2. 点击生成 Agent 适配草稿，或自行逐条确定模块职责：Agent 层、呈现层、共享。迁移结果始终是待审阅草稿。
3. 设置模块的“必用”“Agent 只读”、启停及正文。用户可编辑只读模块，Agent 管理接口不能改写它。
4. 检查编译预览，将已适配版本设为就绪并应用到当前故事。保存新版本与应用版本是两个动作；故事固定到选定版本。
5. Agent 完成本轮模拟及其他工具调用后，单独调用 `rp_present` 提交公开方向包。模块组装模型按需读取和调整未锁模块，编译通过后才启动独立正文模型。

`rp_present` 是唯一直接工具调用的终止步骤；生成成功后结束回合，不再由主 Agent 复述。当前版本支持原生工具呈现，纯 PTC 会话不能启用终止步骤；迁移和预览仍可使用，插件不会擅自改变工具模式。

用户锁由程序检查。Agent 的内容替换、开关、填充和临时模块只进入会话覆盖层，不修改原件或预设版本。未分类、必用空模块、不可解析变量和无效覆盖会阻止正式呈现。写作模型没有世界状态或工具权限，只接收公开方向包、呈现模块与显式提供的公开材料；方向包的事实判断由调用方负责。

## 与其他插件联动

- **RP Studio 1.2**：故事页可打开预设管理；仅显示经过确认的最终正文，主 Agent 的处理文字不作为旁白。原生模式可接收安全正文流，失败草稿不当作已提交叙事。旧故事的旁白保留，回退后的工具记录不能复活旧稿。
- **Loop Studio**：可单独选择“预设迁移”“模块热组装”“最终正文”三个节点的模型，包括已配置的本地模型。未安装 Loop Studio 时沿用会话的模型配置；不复制账号、不增加代理、不自动切换提供方。
- **既有 RP 工具**：保留模拟与结算。旧预设若有专属末端渲染命令，需要调整其末端工作流以使用 `rp_present`；插件不盲目截获未知状态工具。

预设模块原来的脚本、正则、消息深度和宏语义不会自动变成 agent 行为。原始字段可回溯，迁移 skill 会指导职责拆分和未支持项处理，导入本身不会自动启用它们。

## 数据与开发

数据位于 `$DSH_HOME/app-data/rp-last-step/`：来源与预设版本、会话覆盖、冻结呈现记录。按目录备份即可。生成记录页列出已提交稿件；当前剧情分支以 RP Studio 的故事页为准。

```powershell
$env:ELECTRON_SKIP_BINARY_DOWNLOAD = '1'
pnpm install
pnpm rp:test
pnpm rp:package
pnpm rp:smoke
```

产物在 `packages/rp-last-step/artifacts/`。内置迁移 skill 位于发布包 `dist/skills/adapting-sillytavern-rp-presets/`，可在 dsh skill 目录中发现；工作区源稿在仓库 `skills/`。验收使用模拟模型和隔离 home，不发送付费请求或修改已有用户资料。
